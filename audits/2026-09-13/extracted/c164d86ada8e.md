Delivery of the T2S UDFS R2026.JUN and UHB R2026.JUN

As envisaged in the T2S Plan, we have published final versions of the:

    •  T2S User Detailed Functional Specifications R2026.JUN (UDFS R2026.JUN)

    •  T2S User Handbook R2026.JUN (UHB R2026.JUN)

    •  T2S General Functional Specifications R2026.JUN (GFS R2026.JUN)

    •  BILL User Detailed Functional Specifications R2026.JUN

    •  BILL User Handbook R2026.JUN

    •  BDM User Detailed Functional Specifications R2026.JUN

    •  BDM User Handbook R2026.JUN

    •  CRDM User Detailed Functional Specifications R2026.JUN

    •  CRDM User Handbook Book 1 R2026.JUN

    •  CRDM User Handbook Book 2 R2026.JUN

    •  ESMIG User Detailed Functional Specifications R2026.JUN


For the convenience of the readers, all changes in the documents were highlighted in revision marks.

Additionally, we added the appropriate CR references.

The draft intermediate versions of these documents were published on 28 November 2025 and were reviewed
from 01 December 2025 to 19 December 2025. The comments from the market participants have been taken
into account for the final versions to be published on 22 January 2026.

Scope of the delivery
These new versions incorporate Change Requests in the scope of the T2S Release 2026.JUN, including the

editorial Change Requests approved by the CSD Steering Group (CSG) until 02 December 2025.

The exhaustive list of all Change Requests is provided as Annex A to this cover note.

Complementing the information provided in the Service Transition Plans, the Release Notes and the UDFS

itself, a list containing all the T2S messages with their respective links to MyStandards is provided as Annex

B to the Cover Note.
