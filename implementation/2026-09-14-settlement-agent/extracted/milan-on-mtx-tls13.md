MT-X Access: Enabling TLS 1.3
protocol in the PRODUCTION
environment
   To the attention of:                           All clients


   Priority:                                      High


   Topic:                                         MT-X Access Enabling TLS 1.3 PROD



Dear Client
in order to efficiently schedule the activation of the TLS 1.3 protocol in the PRODUCTION
environment, we kindly ask you to check and, if necessary, enable outbound port 8443 for
connecting to MT-X in PRODUCTION. The activation of the TLS 1.3 protocol is required for
security reasons.
If you do not enable this outbound port, you will not be able to connect to the MT-X application
in PRODUCTION.
The go live in PRODUCTION is scheduled for 26 October 2026, so we kindly ask you to proceed
with this activity as soon as possible and provide us with feedback.
We also ask you to carry out the same activity in the TEST environment, as the TLS 1.3 protocol
is already active in TEST.
