1. Introduction


1.1  Target – Objective of the text

The present text describes the possibilities of incoming and out coming of ASCII data
files from the Dematerialized Securities System (DSS) concerning the awareness of
the issuers about their stock holders list as well as any necessary communication for
exchanging data between Euronext Securities Athens and the issuer.


1.2  Structure of the text

The present text divided into the following chapters:

Chapter 1: The present introductory chapter.

Chapter2: Electronic files that coming in and supplied by DSS in order to facilitate
the workflow of the issuers.

Appendix Ι: List of standard files.

1.6  Comma-separated values files (CSV)

A Comma Separated Values (CSV) file is a plain text file that contains a list of data,
that you can create or edit in Excel. Instead of storing information in columns, CSV
files store party-separated information.
