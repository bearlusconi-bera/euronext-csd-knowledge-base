  1. Overview


This guide is intended to help clients complete the two subscription forms for
SWIFT  messaging  related  to  Corporate  Events.   It   is  addressed  to

intermediaries, issuers, issuer agents, and paying agents:


    •  ISO 15022 Subscription Form

    •  ISO 20022 Subscription Form


Clients are reminded that RMA exchanges at the SWIFT level must be in place

between ES-Mil and the client.


At the end of the module, you will find examples and additional details.


Please note that this module is intended for temporary use only, until enhanced

connectivity selection features become available in MyEuronext. Clients will be

informed once these new MyEuronext functionalities are live.


Please read this guide carefully before completing and submitting the forms.

There is no amendment form—each new submission replaces the previous one.

  2. ISO 15022: Subscription Form

SWIFT messages subscription form ISO15022

Applicable to:

    -  Participant / Account Controller – Corporate Events
    -  Issuer Agent / Paying Agent – Corporate Events: Same information
      requested on the other module, subscription of messages restricted to
     MT564 and MT566

Form Completion Instructions:

   2.1    Header Section

    •  Client Name: Enter your legal company name.
    •  Client ID: Provide your client code (ABI code).
If the subscription is for multiple Client IDs, include the additional IDs in a
separate attachment.

    •  Environment: Select TEST, PROD, or both. Selection is mandatory.
    •  Business Service: Select Participant – Communication Channel:
               -  SWIFT FIN: You must join Euronext Securities’ Closed User
           Group if not already done.
               - MQ queues: Service currently not available.
    •  Contact Details: Provide the name, email, and phone number of the
      person or team responsible for connectivity.
    •  Effective Date: Indicate the date on which the subscription should
     become active.

If “PROD” is selected, the configuration will become active starting from the
CA4U go-live date.
    •  BIC & MQ Name:
               -  SWIFT users: Provide your 11-character BIC (when sending or
             receiving SWIFT messages).
               - MQ users: Service currently not available.

   2.2    Event Type Subscriptions

Subscriptions  apply  to  all Corporate  Action event  types,  including

notifications and confirmations.
    •  MT564 – Notification:
               -   Subscriptions are made at function level, not by individual event
             type.

  3. ISO 20022: Subscription Form

SWIFT Messages Subscription Form ISO20022

Applicable to: Participant / Account Controller – Corporate Events
Form Completion Instructions:

   3.1  Header Section

    •  Client ID: Enter your client code (ABI code).
If the subscription covers multiple Client IDs, include the additional IDs in a
separate attachment.
    •  Environment:  Select  TEST, PROD,  or  both.  This  selection  is
      mandatory.
    •  Business Service  :  Select Participant (CE) – Communication
     Channel : SWIFT FIN+.
    •  Contact Details: Provide the email address and phone number of the

      person or team responsible for connectivity.
    •  Effective Date: Indicate the date on which the subscription should
     become active.
    •  Network Addressing:
               -  DN: Participant’s network address
               -  BICFI: BIC of the message owner
               -  BizSvc: has to be filled with CE, IA or PA depending on the role
           (where CE = corporate events, IA = issuer agent, PA = paying
            agent)  as  per  message  specifications  published  in  Swift
           MyStandard (version head.001.001.02)
               -  OtherID: Euronext ID, 5 characters, same as the ABI)

   3.2  Event Types

Subscriptions  apply  to  all  types  of  Corporate  Action  events,  including
notifications and confirmations.

The structure includes:

    •  Event Notifications: Seev.031 and Seev.039

    •  Entitlements: Seev.035 and Seev.044

    •  Processing Status: Seev.044

    •  Confirmations: Seev.036 and Seev.037

   3.3  Instruction and Status Messages

(No Additional action or subscription needed is specified in this section.)

   3.4  Applicable Securities Accounts

    •  Subscriptions are valid only for the specified securities accounts.
    •  You must list the relevant account numbers.
    •  Leaving this section blank means the setup will apply to all the client’s
      accounts.

   3.5  Sign-off

       - Provide the date, authorized signatory name, and signature.

If a client wants an account operator to receive messages, a separate module
must be completed quoting the BIC of the account operator.

Note for Issuer Agent / Paying Agent:
